# Inventory Management System (IMS)

## 📌 Project Overview

The **Inventory Management System (IMS)** is a web-based application developed as a **3rd Year Individual Project** using the **MERN stack**. It is designed to replace manual inventory handling in grocery stores with a **real-time, automated, and scalable solution**.

The system helps reduce waste, prevent stock shortages, and improve decision-making through accurate tracking and analytics.

---

## 🎯 Problem Addressed

Manual inventory systems are error-prone and inefficient, often leading to:

* Overstocking or stockouts
* Expired items and increased waste
* Poor supplier coordination

IMS solves these issues through automation and real-time visibility.

---

## ⚙️ Key Features

* **Real-Time Inventory Tracking** – Live stock level updates
* **Automated Alerts** – Low-stock and expiry notifications
* **Role-Based Access Control** – Admin, Manager, Staff, Supplier roles
* **Supplier Order Management** – Order creation, confirmation, and tracking
* **Integrated Payment Gateway** – Secure supplier payments via **PayHere**
* **Reports & Analytics** – Insights for better inventory planning

---

## 🛠️ Technology Stack

* **Frontend:** React.js
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Payment Gateway:** PayHere


Developed for academic purposes.
